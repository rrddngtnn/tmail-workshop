# Security policy

Please do not disclose vulnerabilities, credentials, or private mail in public issues or pull requests. Use GitHub's private vulnerability reporting if it is enabled for this repository; otherwise contact a maintainer privately to arrange a secure reporting channel. No private reporting channel has been verified yet.

Include the affected version, impact, and steps to reproduce using non-sensitive sample data. Allow maintainers time to investigate and coordinate disclosure. Support and response times are not guaranteed.
